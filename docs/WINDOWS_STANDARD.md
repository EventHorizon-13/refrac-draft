# RefracDraft Standard — Windows x64 便携版

这是独立的标准模块版本。解压 `RefracDraft-Standard-Windows-x64-portable` 构建产物后，保留整个目录并运行 `RefracDraft-Standard.exe`。

## 适用轮廓

- **普通**：长度 × 膨胀长度的正面，长度 × 厚度的夹板面。
- **正敲大小头**：长度 × 大头/小头的正面梯形 + 长度 × 厚度的夹板面，共两个视图。
- **侧敲大小头**：长度 × 膨胀长度的正面、厚度 × 大头/小头的侧面梯形 + 长度 × 厚度的夹板面，共三个视图。

本版本不接收参数化缺角、开槽、台阶、自定义异形轮廓或 DXF 异形夹板面模板。导入包含这些字段的 JSON/Excel 会给出模块编号和错误说明。普通、正敲、侧敲的尺寸、夹板和锚固件参数仍按原有规则处理。

## 参数输入

参数区采用表格样式，一行就是一个模块。表头不再重复单位，单元格文字统一居中；列宽整体收窄。新增「折叠方式」列，可选择折叠、半折叠、层叠或自定义。材质、夹板和胶管列只显示型号本身，图纸说明仍输出完整名称。容重列前移，备注固定放在最后。勾选「大小头」后显示大头、小头以及正敲/侧敲类型，膨胀长度自动锁定为大头尺寸。锚固件默认收起，勾选后才显示位置、间距、锚固数量、类型、锚固件长度、锚固型号、螺栓、插针 φ、胶管和嵌入深度；嵌入深度只在类型为「菱形」时显示，菱形锚固件不显示、不保存插针。复选列只显示勾选框，不再显示“是/否”。

表格支持单击直接输入，选项列单击弹出菜单，菜单末项保留自定义输入；复选框单击即切换并居中显示。表格也支持拖动右下角填充柄复制到相邻行，以及从 Excel/WPS 粘贴制表符分隔的多格数据。双击复选列表头可全选/取消全选，双击其他列表头可修改整列并保留自定义输入。`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；单元格编辑、填充、整列修改、勾选、添加和删除模块均进入历史记录。新增模块会复制当前最后一行并自动生成下一个编号。

只有模块折叠方式、材质、类型、夹板型号、锚固件类型、锚固件材质、插针和胶管提供预设菜单；菜单保留“自定义”入口，其余列仍可直接输入任意值。夹板型号提供 9厘、8厘、6厘，插针提供 8、6、5，胶管提供 25、32。夹板面不再单独输入宽高，其尺寸固定由长度和厚度生成。

夹板面锚固件的纵向中心按参考块从夹板面顶边向下定位：M型约 35.439 mm；菱形不再沿用源块的 70 mm 默认值，而是严格使用参数中的真实嵌入深度，使图形、尺寸标注和明细三者一致。夹板面会标注各锚固件位置及其分段尺寸；菱形锚固件从夹板面外缘到实际深度位置标注数值，不在尺寸文字中重复“嵌入深度”。侧视图只绘制一个代表性锚固件符号；M型符号按参考膨胀面方向水平翻转，菱形侧视符号按参考块旋转和缩放，并由嵌入深度从侧面外缘向内定位。侧敲主视图同时绘制两条小头轮廓线；无锚固件时，普通/大小头模块的正面和侧面再绘制四根渐短的膨胀面标记。

图纸按模块主视图、侧视图、夹板面和明细的实际宽度自动分列，列间保持固定间距，超出 A4 内框可用宽度时自动分页。每个模块作为整体在栏内水平居中，使左右空白尽量均衡；主视图、夹板面图和明细文字内部仍采用同一左基准线。最后一页可以只包含一个模块。预览页周围的空白区域跟随系统深浅主题，纸张本身保持白色。

DXF 中所有模块几何按 1:1 实际毫米绘制，A4 图框和标题栏固定放大 10 倍（按 1:10 出图）。DXF 标注使用参考文件中的 `_10` 标注样式及其 20 倍标注总比例；文字样式「工程字」「大字体」使用所选 SHX 正文与大字体文件。明细说明合并为一个 MTEXT，字号 4.2 mm，使用精确行距，避免压到标题栏。PDF 不再叠加参考 PDF，而是先生成与导出 DXF 完全同源的图纸文件，再从该 DXF 渲染 A4 矢量 PDF；渲染时遵循图层的打印开关，`不打印`/`Defpoints` 等非打印图层不会进入 PDF。

输出设置可选择任意 SHX 字体目录，并分别指定正文字体和大字体；不局限于 `gbenor.shx`、`gbcbig.shx`。便携版使用与辊密封生成器相同的 MLightCAD 矢量 PDF 渲染链，任意选中的 SHX 会在导出时映射为渲染器正文/大字体。目录也可继续放 `.ttf`、`.otf`、`.ttc` 作为无 SHX 时的回退字体。

不再显示名称、单独的几何类型、左右端高度、夹板面宽高和标注定位开关。正敲/侧敲只作为大小头类型出现；普通模块不勾选「大小头」即可。

保存 JSON 时，程序仍把三组数据存为独立的 `modules`、`boards`、`anchors` 参数表，并用模块编号关联。现有三工作表 Excel 和现有 JSON 格式可直接导入；其中异形项目会被拒绝，不会静默改成矩形。

修改后点击「预览」，再导出 DXF 或 PDF。预览和两种导出都会显示阶段进度，避免长任务看起来像卡死。预览区域分为左侧输出设置和右侧图纸预览：左侧可设置工作目录、自定义文件名、SHX 字体目录和字体选择，并直接执行 DXF/PDF 导出。程序会记住上次工作目录和字体目录；默认文件名采用 `模块加工图_月日_`，例如 `模块加工图_1118_.dxf`。文件名会自动清理 Windows 不允许的字符，导出的 DXF 与 PDF 使用同一个文件名主体。参考 DXF/PDF 和 PDF 字体已随便携版打包，启动位置不影响资源读取。

Windows 构建流程会运行打包后的程序，检查 B2 正敲示例的表格参数映射、折叠方式、短型号、无单位表头、容重列顺序、复选框显示、模块/夹板/锚固件明细字段、大小头与锚固件条件显示、模块切换与增删、拖动填充、撤销重做、默认文件名、参考文件、可编辑 DXF 和从 DXF 渲染的矢量 PDF。该版本仍是开发预览版，尚未完成全部黄金样板和人工 Windows 交互验收。
