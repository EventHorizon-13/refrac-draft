# RefracDraft Standard — Windows x64 便携版

这是独立的标准模块版本。解压 `RefracDraft-Standard-Windows-x64-portable` 构建产物后，保留整个目录并运行 `RefracDraft-Standard.exe`。

## 适用轮廓

- **普通**：标准矩形/方形的正面和夹板面。
- **正敲**：正面两端高度不同，正面梯形 + 矩形夹板面，共两个视图。
- **侧敲**：正面矩形、侧面梯形 + 矩形夹板面，共三个视图。

本版本不接收参数化缺角、开槽、台阶、自定义异形轮廓或 DXF 异形夹板面模板。导入包含这些字段的 JSON/Excel 会给出模块编号和错误说明。普通、正敲、侧敲的尺寸、夹板和锚固件参数仍按原有规则处理。

## 参数输入

主窗口只有一张统一参数表，一行对应一个模块编号。表头用「模块·」「夹板·」「锚固件·」区分字段，横向滚动查看。保存 JSON 时，程序仍把三组数据存为独立的 `modules`、`boards`、`anchors` 参数表，并用模块编号关联。现有三工作表 Excel 和现有 JSON 格式可直接导入；其中异形项目会被拒绝，不会静默改成矩形。

修改后点击「生成预览」，再导出 DXF 或 PDF。参考 DXF/PDF 已随便携版打包，启动位置不影响资源读取。

Windows 构建流程会运行打包后的程序，检查 B2 正敲示例在统一参数表中的往返一致性、参考文件、可编辑 DXF 和矢量 PDF。该版本仍是开发预览版，尚未完成全部黄金样板和人工 Windows 交互验收。
