# RefracDraft Standard — Windows x64 便携版

这是独立的标准模块版本。解压 `RefracDraft-Standard-Windows-x64-portable` 构建产物后，保留整个目录并运行 `RefracDraft-Standard.exe`。

## 适用轮廓

- **普通**：长度 × 膨胀长度的正面，长度 × 厚度的夹板面。
- **侧敲大小头**：长度 × 大头/小头的正面梯形 + 长度 × 厚度的夹板面，共两个视图。
- **正敲大小头**：长度 × 膨胀长度的正面、厚度 × 大头/小头的侧面梯形 + 长度 × 厚度的夹板面，共三个视图。

所有轮廓类型在未安装夹板时，都在夹板面中央标「无夹板」。安装了夹板且没有锚固件时，中央标「夹板」。

每行「厚度」旁都有「异形模块」按钮。弹窗支持四种夹板面轮廓，可修改 a、b、c、d 并实时查看示意图，单独旋转或镜像各个切口，也可组合多个切口。删除全部切口即可恢复矩形。外轮廓的最大长度和厚度由主参数表提供。异形参数随 JSON 项目保存，Excel 继续使用原有参数列。

## 参数输入

参数区采用表格样式，一行就是一个模块。表头不再重复单位，单元格文字统一居中；列宽整体收窄。新增「折叠方式」列，可选择折叠、半折叠、层叠或自定义。材质、夹板和胶管列只显示型号本身，图纸说明仍输出完整名称。容重列前移，备注固定放在最后。勾选「大小头」后显示大头、小头以及正敲/侧敲类型，膨胀长度自动锁定为大头尺寸。锚固件默认收起，勾选后才显示位置、间距、锚固数量、类型、锚固件长度、锚固型号、螺栓、插针 φ、胶管和嵌入深度；嵌入深度只在类型为「菱形」时显示，菱形锚固件不显示、不保存插针。复选列只显示勾选框，不再显示“是/否”。

单击单元格只选中，方向键可在可用单元格间移动。开始输入字符后进入编辑，回车保存并移到同列下一可用行。点击或用键盘移动到带预设的单元格会自动展开下拉，方向键和回车仍可换格。双击预设单元格可直接输入自定义值，大小头类型仅接受正敲或侧敲。复选框仍可单击切换。表格也支持拖动右下角填充柄复制到相邻行，以及从 Excel/WPS 粘贴制表符分隔的多格数据。双击复选列表头可全选/取消全选，双击其他列表头可修改整列并保留自定义输入。`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；单元格编辑、填充、整列修改、勾选、添加和删除模块均进入历史记录。新增模块会复制当前最后一行并自动生成下一个编号。

只有模块折叠方式、材质、类型、夹板型号、锚固件类型、锚固件材质、螺栓、插针和胶管提供预设菜单；折叠方式、锚固件类型等支持自定义值，正敲和侧敲按固定类型选择。自定义的折叠方式和锚固件名称会保存在 JSON 中，并出现在图纸说明。夹板型号提供 9厘、8厘、6厘，螺栓提供 M8、M10 和自定义，插针提供 8、6、5，胶管提供 25、32。夹板面不再单独输入宽高，其尺寸固定由长度和厚度生成。

M 型锚固件中心距夹板面顶边约 35.439 mm。菱形锚固件的嵌入深度从模块上表面量到锚固件上缘，夹板面标注该尺寸，图纸说明省去重复的嵌入深度。夹板面同时标注锚固件位置及其分段尺寸。侧视图只绘制一个代表性锚固件符号；M型符号按参考膨胀面方向水平翻转，菱形侧视符号按参考块旋转和缩放，并由嵌入深度从侧面外缘向内定位。正敲主视图同时绘制两条小头轮廓线；无锚固件时，普通/大小头模块的正面和侧面再绘制四根渐短的膨胀面标记。

旁插、快插仍各自可选，正面、侧面和夹板面采用《示例.pdf》中的同组锚固件图形。夹板面两排圆孔属于锚固件符号。夹板加工开口由单独的夹板参数指定。

图纸按模块主视图、侧视图、夹板面和明细的实际宽度自动分列，列间保持固定间距，超出 A4 内框可用宽度时自动分页。长度 350 mm 及以内的模块，图形和明细各自对齐同一栏中心。超过 350 mm 的模块，明细与图形左沿对齐。明细各行左对齐。最后一页可以只包含一个模块。预览页周围的空白区域跟随系统深浅主题，纸张本身保持白色。

DXF 中所有模块几何按 1:1 实际毫米绘制，A4 图框和标题栏固定放大 10 倍（按 1:10 出图）。DXF 标注使用参考文件中的 `_10` 标注样式及其 20 倍标注总比例；文字样式「工程字」「大字体」使用所选 SHX 正文与大字体文件。A4 出图尺寸标注高 3.2 mm，明细使用字高 4.5 mm 的可编辑 MTEXT，按各栏剩余宽度换行。模块间分隔线距图框上边和标题栏顶部各留 150 mm 模型空间距离。PDF 不再叠加参考 PDF，而是先生成与导出 DXF 完全同源的图纸文件，再从该 DXF 渲染 A4 矢量 PDF；渲染时遵循图层的打印开关，`不打印`/`Defpoints` 等非打印图层不会进入 PDF。

缺省 PDF 使用随程序打包的思源宋体。可把指定字体放到与 `RefracDraft-Standard.exe` 同目录的 `fonts/`。程序自动匹配正文字体与大字体，优先使用 `gbenor.shx` 和 `gbcbig.shx`。便携版使用 MLightCAD 渲染 SHX 矢量 PDF。目录也可继续放 `.ttf`、`.otf`、`.ttc` 作为无 SHX 时的回退字体。

不再显示名称、单独的几何类型、左右端高度、夹板面宽高和标注定位开关。正敲/侧敲只作为大小头类型出现；普通模块不勾选「大小头」即可。

随包的六模块 Excel 示例在一张「标准版」工作表中提供与界面相同的表头和列顺序。可直接通过「导入 Excel」打开。大小头、夹板和锚固件列可填「是／否」或布尔值。旧的三工作表 Excel 继续支持。v0.1.4 的单表 Excel 如使用旧称，导入前请对调「类型」列中的正敲和侧敲。JSON 仍按模块编号关联 `modules`、`boards`、`anchors` 三组数据。

修改后点击「预览」，再导出 DXF 或 PDF。生成预览和 DXF 按完成阶段更新进度条，PDF 另外逐页更新进度，写入成功后显示完成。标题和页码悬浮在图纸视口上方。多页预览中，页码上箭头和滚轮向上都返回上一页，向下进入下一页。预览区域分为左侧输出设置和右侧图纸预览：左侧可设置工作目录、自定义文件名，并直接执行 DXF/PDF 导出。预览直接显示生成的 PDF 页，同一字体目录下导出会保存这份 PDF。程序会记住上次工作目录；默认文件名采用 `模块加工图_月日_`，例如 `模块加工图_1118_.dxf`。文件名会自动清理 Windows 不允许的字符，导出的 DXF 与 PDF 使用同一个文件名主体。参考 DXF/PDF 和 PDF 字体已随便携版打包，启动位置不影响资源读取。

Windows 构建流程会运行打包后的程序，检查 B2 侧敲示例的表格参数映射、折叠方式、短型号、无单位表头、容重列顺序、复选框显示、模块/夹板/锚固件明细字段、大小头与锚固件条件显示、模块切换与增删、拖动填充、撤销重做、默认文件名、参考文件、可编辑 DXF 和从 DXF 渲染的矢量 PDF。该版本仍是开发预览版，尚未完成全部黄金样板和人工 Windows 交互验收。


## 版本与更新

窗口标题和「关于」显示程序版本。点击「关于 → 检查更新」可查询 GitHub 上的标准版正式发布，找到新版本后可直接打开便携包下载。将新版解压到新目录，如需使用原字体，将旧版的 `fonts/` 内容复制到新版目录。发布标签为 `standard-v<版本号>`，版本号取自 `pyproject.toml`。
