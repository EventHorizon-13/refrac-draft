# RefracDraft Standard — Windows x64 便携版

这是独立的标准模块版本。解压 `RefracDraft-Standard-Windows-x64-portable` 构建产物后，保留整个目录并运行 `RefracDraft-Standard.exe`。主工具栏的「置顶」可让窗口保持在其他窗口上方，程序会记住该设置。

## 适用轮廓

- **普通**：长度 × 膨胀长度的正面，长度 × 厚度的夹板面。
- **正常敲大小头**：长度 × 大头/小头的正面梯形 + 长度 × 厚度的夹板面，共两个视图。
- **侧敲大小头**：长度 × 膨胀长度的正面、厚度 × 大头/小头的侧面梯形 + 长度 × 厚度的夹板面，共三个视图。

所有轮廓类型在未安装夹板时，都在夹板面中央标「无夹板」。安装了夹板且没有锚固件时，中央标「夹板」。

夹板面保留整体投影、锚固件和加工尺寸。参数表可分别勾选「上板图」「下板图」，在总图之外绘制所选板件的实际边界和尺寸。单独出板图后，夹板面可省去对应板件的缺口引线。勾选状态随 JSON 和 Excel 保存，旧表头「上夹板」「下夹板」仍可导入。

每行「厚度」旁的「异形」列会显示「非异形」或「异形 ✓」，点击均可编辑切口。选择「夹板面」「正面」或「侧面」页签后，可在该面添加、旋转、镜像切口。每个切口的剪切深度沿所选面的垂直轴量取，留空表示贯通。起切面只决定深度方向，轮廓坐标始终按当前视图输入。

- 夹板面沿膨胀方向切，可从上夹板或下夹板起切。
- 正面沿厚度方向切，可从正面或背面起切。
- 侧面沿模块长度方向切，可从左端或右端起切。侧面页签按图纸左视图定位，靠近夹板的一边在左。

有正面或侧面切口时，先合并各切口的实际切除区域，再从剩余材料生成正面、侧面及夹板面。交叉处按剩余实体绘制可见线和隐藏线。盲切用直引线标注起切面及深度。剪切切断整个模块、未碰到实体或移除锚固件安装材料时，出图会指出原因。JSON 和 Excel 保存加工面、起切面及剪切深度。旧表中没有「加工面」列的切口沿用夹板面定义。

凹槽的 d 是肩部相对 b 的有向尺寸，可输入负数，0 表示齐平。锚固件遇到台阶时保留横向定位，按承托范围内的实际台阶面向内落座。

「类型 3 · 斜切角」的 a 为模板的水平切除尺寸，b 为竖向切除尺寸。通过旋转或镜像选择角落。同一边的两个斜切角可以共用一个端点。旧项目单参数斜切按原轮廓出图，打开异形编辑器时会显示等效的 a、b。

「类型 4 · 斜切台阶」允许 a 为 0，预览会标出斜边起切的角点。a、b、c、d 的尺寸线和输入表头使用对应颜色，预览字母会自动错开。

## 参数输入

参数表中按住 `Shift` 滚动鼠标滚轮可横向浏览。整表没有勾选大小头、夹板或锚固件时，隐藏该组的附加列；重新勾选后恢复原值。锚固件类型和材质排在锚固件参数最前。

参数区采用表格样式，一行就是一个模块。表头不再重复单位，备注单元格左对齐，其他单元格文字居中；列宽整体收窄。新增「折叠方式」列，可选择折叠、半折叠、层叠或自定义。材质、夹板和胶管列只显示型号本身，图纸说明仍输出完整名称。容重列前移，备注列加宽并固定放在最后。大小头备注选「自动」时，图纸写入「正常敲」或「侧敲」。参数表和图纸备注中的敲型文字用大一号红字显示。勾选「大小头」后显示大头、小头以及正常敲/侧敲类型，膨胀长度自动锁定为大头尺寸。锚固件默认收起，勾选后才显示位置、间距、锚固数量、类型、锚固件长度、锚固型号、螺栓、插针 φ、胶管和嵌入深度；嵌入深度适用于「菱形」和「焊接菱形」。这两种类型均隐藏插针字段。复选列只显示勾选框，不再显示“是/否”。

单击单元格只选中，方向键可在可用单元格间移动。直接键入即可替换原值。编辑时，左右键先移动光标，到文本边界后再按同方向键会保存并换格，上下键直接保存并换行。回车保存并移到同列下一可用行。点击或用键盘移动到带预设的单元格会自动展开下拉。展开时按 ↑↓ 高亮选项，按 Enter 确认并停留在当前格，←→ 继续切换单元格，Esc 关闭下拉。双击预设单元格可直接输入自定义值，大小头类型仅接受正常敲或侧敲。复选格可单击切换，也可按 `Ctrl+Enter` 在当前格切换。表格也支持拖动右下角填充柄复制到相邻行，以及从 Excel/WPS 粘贴制表符分隔的多格数据。双击复选列表头可全选/取消全选，双击其他列表头可修改整列并保留自定义输入。`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；单元格编辑、填充、整列修改、勾选、添加和删除模块均进入历史记录。新增模块会复制当前最后一行并自动生成下一个编号。

折叠方式、材质、大小头类型、夹板型号、锚固件位置和材质等字段提供预设菜单；折叠方式、锚固件类型等支持自定义值，正常敲和侧敲按固定类型选择。自定义的折叠方式和锚固件名称会保存在 JSON 中，并出现在图纸说明。夹板型号提供 9厘、8厘、6厘，螺栓提供 M8、M10 和自定义，插针提供 8、6、5，胶管提供 25、32。夹板面不再单独输入宽高，其尺寸固定由长度和厚度生成。

锚固件「位置」默认选「均分」，单元格只显示首个锚固件的计算位置；下拉菜单仍可切换均分或手填。单个锚固件居中，多个按模块长度除以锚固件数量得到间距，首个位置为间距的一半。改用自定义位置即可手填间距。

「锚固件长度」选「自动」时，M 型和菱形的插针长度按安装位置的膨胀长度减 50 mm，取不超过该值的最大常用规格。大小头按锚固件所在截面计算。同一模块有多个安装点时，采用最短截面作为共同依据。M 型常用 240、220、200、180、150、120 mm，菱形常用 230、200、180、150、120 mm。低于 120 mm 时自动值留空，可手动填写。

M 型锚固件中心距夹板面顶边约 35.439 mm。菱形锚固件的嵌入深度从模块上表面量到锚固件上缘，夹板面标注该尺寸，图纸说明省去重复的嵌入深度。夹板面同时标注锚固件位置及其分段尺寸。侧视图只绘制一个代表性锚固件符号；M型符号按参考膨胀面方向水平翻转，菱形侧视符号按参考块旋转和缩放，并由嵌入深度从侧面外缘向内定位。侧敲主视图同时绘制两条小头轮廓线；无锚固件时，普通/大小头模块的正面和侧面再绘制四根渐短的膨胀面标记。

选「焊接M型」或「焊接菱形」后填写「螺栓外露长度」，焊接菱形再填写「嵌入深度」。备注选「自动」时显示螺栓总长和外露长度，大小头模块同时显示敲型。手填备注按输入出图，选择「留空」时省略备注。外露引线从靠近模块的螺杆处引出，焊接菱形另标螺栓外露、嵌入和总长尺寸。螺栓总长等于嵌入深度加外露长度，锚固件长度可单独填写。旧版焊接菱形项目若没有嵌入深度，出图前需补填。

旁插、快插仍各自可选，正面、侧面和夹板面采用《示例.pdf》中的同组锚固件图形。夹板面两排圆孔属于锚固件符号。夹板加工开口由单独的夹板参数指定。

图纸按各视图和明细的实际宽度自动分列，超出 A4 内框可用宽度时自动分页。明细优先放在图形下方，余高不足时再放侧边。长度 350 mm 及以内的模块，明细居中布置。超过 350 mm 的模块，明细与图形左沿对齐。明细各行左对齐。预览页周围的空白区域跟随系统深浅主题，纸张本身保持白色。

四个视图在宽度足够时按两行两列排列。同行间距包括尺寸和引线的实际占用。同一侧重叠的尺寸跨度越大越靠外，互不干涉的小尺寸尽量共用一条尺寸线。

多页图纸才显示页码及预览分页控件。单页仍可按设置显示文件名。引线用棕橙色，快插和旁插锚固件用紫色，无锚固件的正面及已有侧视图使用蓝灰色层纹线。

DXF 中所有模块几何按 1:1 实际毫米绘制，A4 横向普通图页以 1:10 出图，使用 `_10` 标注样式。单个模块超出 1:10 可用范围时，切换到独立的 A4 横向 1:20 图页，使用参考文件中的 `_20` 样式，纸面标注、视图文字及明细字高增加 10%。图框和标题栏随图页比例放大，模块几何及测量值仍按真实毫米保存。文字样式「工程字」「大字体」使用所选 SHX 正文与大字体文件，明细为可编辑 MTEXT。PDF 不再叠加参考 PDF，而是先生成与导出 DXF 完全同源的图纸文件，再从该 DXF 渲染 A4 矢量 PDF；渲染时遵循图层的打印开关，`不打印`/`Defpoints` 等非打印图层不会进入 PDF。

缺省 PDF 使用随程序打包的思源宋体。可把指定字体放到与 `RefracDraft-Standard.exe` 同目录的 `fonts/`。程序自动匹配正文字体与大字体，优先使用 `gbenor.shx` 和 `gbcbig.shx`。便携版使用 MLightCAD 渲染 SHX 矢量 PDF。目录也可继续放 `.ttf`、`.otf`、`.ttc` 作为无 SHX 时的回退字体。

不再显示名称、单独的几何类型、左右端高度、夹板面宽高和标注定位开关。正常敲/侧敲只作为大小头类型出现；普通模块不勾选「大小头」即可。

随包的六模块 Excel 示例在一张「标准版」工作表中提供与界面相同的表头和列顺序。可直接通过「导入 Excel」打开。大小头、夹板和锚固件列可填「是／否」或布尔值。旧的三工作表 Excel 继续支持。含「联动设置」的旧版 Excel 导入时按已保存的敲型语义转换，保留原有几何。无版本标记的工作簿按当前敲型含义解读，旧称「正敲」仍可导入。JSON 仍按模块编号关联 `modules`、`boards`、`anchors` 三组数据。

锚固件材质选择「自动」时，模块材质等级低于 1430 默认使用 304，1430 及以上默认使用 310；手动填写的锚固件材质不随模块材质修改。图框左下角始终显示「第 X 页 共 Y 页」，若启用文件名显示则紧随文件名（仅隔两个空格），两者作为一个可编辑的 DXF 文字对象输出；DXF 和 PDF 使用同一标注。

修改后点击「预览」，再导出 DXF 或 PDF。生成预览和 DXF 按完成阶段更新进度条，PDF 另外逐页更新进度，写入成功后显示完成。标题和页码悬浮在图纸视口上方。多页预览中，页码上箭头和滚轮向上都返回上一页，向下进入下一页。预览区域分为左侧输出设置和右侧图纸预览：左侧可设置工作目录、自定义文件名，并直接执行 DXF/PDF 导出。预览直接显示生成的 PDF 页，同一字体目录下导出会保存这份 PDF。程序会记住上次工作目录；默认文件名采用 `模块加工图_月日_`，例如 `模块加工图_1118_.dxf`。文件名会自动清理 Windows 不允许的字符，导出的 DXF 与 PDF 使用同一个文件名主体。参考 DXF/PDF 和 PDF 字体已随便携版打包，启动位置不影响资源读取。

Windows 构建流程会运行打包后的程序，检查 B2 正敲示例的表格参数映射、折叠方式、短型号、无单位表头、容重列顺序、复选框显示、模块/夹板/锚固件明细字段、大小头与锚固件条件显示、模块切换与增删、拖动填充、撤销重做、默认文件名、参考文件、可编辑 DXF 和从 DXF 渲染的矢量 PDF。v0.2.0 是正式发布版本；已通过自动化单元测试和 Windows 便携版冒烟验证。对尚未实现的高级异形模块功能，以及全部黄金样板和人工 Windows 交互验收，仍按项目开发状态追踪。


## 版本与更新

在输出设置区点击「预览」或按 `F5` 后台生成图纸；多页 PDF 可同时渲染两页，翻页时后台预取相邻页。「选择」右侧的「打开」会在文件管理器中打开工作目录。预览区的四角图标（`F11`）在当前窗口内切换全窗口预览，不进入系统全屏；再次点击图标或按 `Esc` 返回。

窗口标题和「关于」显示程序版本。点击「关于 → 检查更新」可查询 GitHub 上的标准版正式发布，找到新版本后可直接打开便携包下载。将新版解压到新目录，如需使用原字体，将旧版的 `fonts/` 内容复制到新版目录。发布标签为 `standard-v<版本号>`，版本号取自 `pyproject.toml`。
