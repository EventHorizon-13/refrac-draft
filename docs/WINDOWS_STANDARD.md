# RefracDraft Standard — Windows x64 便携版

这是独立的标准模块版本。解压 `RefracDraft-Standard-Windows-x64-portable` 构建产物后，保留整个目录并运行 `RefracDraft-Standard.exe`。

## 适用轮廓

- **普通**：长度 × 膨胀长度的正面，长度 × 厚度的夹板面。
- **正敲大小头**：长度 × 大头/小头的正面梯形 + 长度 × 厚度的夹板面，共两个视图。
- **侧敲大小头**：长度 × 膨胀长度的正面、厚度 × 大头/小头的侧面梯形 + 长度 × 厚度的夹板面，共三个视图。

本版本不接收参数化缺角、开槽、台阶、自定义异形轮廓或 DXF 异形夹板面模板。导入包含这些字段的 JSON/Excel 会给出模块编号和错误说明。普通、正敲、侧敲的尺寸、夹板和锚固件参数仍按原有规则处理。

## 参数输入

参数区采用表格样式，一行就是一个模块。每行保留编号、长度、膨胀长度、厚度、模块材质、模块数量、夹板开关和夹板类型；勾选「大小头」后显示大头、小头以及正敲/侧敲类型，膨胀长度自动锁定为大头尺寸。锚固件默认收起，勾选后才显示位置、间距、锚固数量、类型、锚固件长度、锚固件材质、螺栓 M、插针 φ、胶管和嵌入深度；嵌入深度只在类型为「菱形」时显示，菱形锚固件不显示、不保存插针。容重和备注固定放在参数表最后。表格支持选中单元格或区域后拖动右下角填充柄复制到相邻行，也支持从 Excel/WPS 粘贴制表符分隔的多格数据；新增模块会复制当前最后一行并自动生成下一个编号。

长度、膨胀长度、厚度、大小头、材质、数量、夹板类型、螺栓规格、插针直径和胶管均使用可编辑下拉框：下拉框提供常用值，也可以直接输入自定义值。锚固件类型提供 M型、菱形、旁插、快插、焊接菱形和自定义。夹板面不再单独输入宽高，其尺寸固定由长度和厚度生成。

夹板面锚固件的纵向中心按参考块从夹板面顶边向下定位：M型约 35.439 mm，菱形约 70 mm。夹板面会标注各锚固件位置及其分段尺寸；菱形锚固件还从夹板面外缘到实际深度位置标注数值，不在尺寸文字中重复“嵌入深度”，数值直接读取参数。侧视图只绘制一个代表性锚固件符号；M型符号按参考膨胀面方向水平翻转，菱形侧视符号按参考块旋转和缩放，并由嵌入深度从侧面外缘向内定位。侧敲主视图同时绘制两条小头轮廓线；无锚固件时，普通/大小头模块的正面和侧面再绘制四根渐短的膨胀面标记。

图纸按模块主视图、侧视图、夹板面和明细的实际宽度自动分列，列间保持固定间距，超出 A4 内框可用宽度时自动分页。每个模块作为整体在栏内水平居中，使左右空白尽量均衡；主视图、夹板面图和明细文字内部仍采用同一左基准线。最后一页可以只包含一个模块。预览页周围的空白区域跟随系统深浅主题，纸张本身保持白色。

DXF 中所有模块几何按 1:1 实际毫米绘制，A4 图框和标题栏固定放大 10 倍（按 1:10 出图）。DXF 标注使用参考文件中的 `_10` 标注样式及其 20 倍标注总比例；文字样式「工程字」「大字体」统一绑定 `gbenor.shx`、`gbcbig.shx` 大字体。明细各行使用同一字号。PDF 不再叠加参考 PDF，而是先生成与导出 DXF 完全同源的图纸文件，再从该 DXF 渲染 A4 矢量 PDF；便携版内置 OFL 授权中文字体，解决 PDF 中 SHX 字体在非 CAD 环境的显示问题。

不再显示名称、单独的几何类型、左右端高度、夹板面宽高和标注定位开关。正敲/侧敲只作为大小头类型出现；普通模块不勾选「大小头」即可。

保存 JSON 时，程序仍把三组数据存为独立的 `modules`、`boards`、`anchors` 参数表，并用模块编号关联。现有三工作表 Excel 和现有 JSON 格式可直接导入；其中异形项目会被拒绝，不会静默改成矩形。

修改后点击「生成预览」，再导出 DXF 或 PDF。预览区域分为左侧输出设置和右侧图纸预览：左侧可设置工作目录、自定义文件名、选择预览页，并直接执行 DXF/PDF 导出；文件名会自动清理 Windows 不允许的字符，导出的 DXF 与 PDF 使用同一个文件名主体。参考 DXF/PDF 和 PDF 字体已随便携版打包，启动位置不影响资源读取。

Windows 构建流程会运行打包后的程序，检查 B2 正敲示例的表格参数映射、模块/夹板/锚固件明细字段、大小头与锚固件条件显示、模块切换与增删、拖动填充、参考文件、可编辑 DXF 和从 DXF 渲染的矢量 PDF。该版本仍是开发预览版，尚未完成全部黄金样板和人工 Windows 交互验收。
