Windows x64 便携预览版。请将 ZIP 完整解压到独立目录，再运行 `RefracDraft-Standard.exe`。

## 本次更新

- 新增焊接 M 型和焊接菱形锚固件，可设置螺栓外露长度。焊接菱形同时标注总长、外露和埋入长度。
- 超出 1:10 单页可用范围的模块自动使用独立的 A4 横向 1:20 图页。长页采用 `_20` 标注样式，纸面标注及明细字高增加 10%，DXF 保留实际毫米尺寸。
- 夹板面异形可逐个设置剪切深度。留空表示贯通，止口投影、图纸明细和 Excel／JSON 项目数据随设置更新。
- 基于 v0.2.0，保留页脚页码和锚固件材质联动。

## 验证

Windows x64 便携应用通过打包冒烟测试，5 项定向回归通过。使用成对的自制 SHX 测试字体核对了混合比例 PDF。4700 mm 模块在 1:20 页上实测宽 235 mm。AutoCAD 实机及生产字体组合仍待验收。
