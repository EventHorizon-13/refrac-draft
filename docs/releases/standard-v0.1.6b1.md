## 更新内容

- 参数表每行「厚度」右侧新增「异形模块」按钮。弹窗支持四种夹板面轮廓，尺寸变化实时显示在示意图上。切口可单独旋转 90°、镜像及组合。
- 异形夹板面的最大外尺寸使用表格中的长度和厚度。轮廓参数随 JSON 项目保存，支持撤销和重做。删除全部切口可恢复矩形。
- 根据《示例.pdf》修正旁插和快插锚固件的正面、侧面与夹板面符号。DXF 保留可编辑圆弧，快插不再自动套用旧的 B10 候选开口。

本版以 GitHub 预发行发布，标准版自动更新仍跟踪正式版本。
