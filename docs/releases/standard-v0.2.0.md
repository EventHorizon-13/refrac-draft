# RefracDraft Standard v0.2.0 正式版

Windows x64 便携版。下载 ZIP 完整解压后运行 `RefracDraft-Standard.exe`。

## 正式版改进

- 修复图框左下角文件名与页码相隔过远的问题。两者合并为一个可编辑的 DXF 文字对象，文件名后仅保留两个空格，例如：`模块加工图__1121__测试  第1页 共3页`。无文件名时仍显示页码。
- 修复模块材质修改后锚固件材质未自动更新的问题：自动模式下，模块等级低于 1430 默认 304，1430 及以上默认 310；手动指定值不被覆盖。
- 多页 DXF 和 PDF 共用页脚文字与自动分页结果。
- 继续包含标准版现有的 Excel 导入、参数化二维图纸、A4 自动分页、可编辑 DXF 及 PDF 导出、表格批量编辑等功能。

## 验证与限制

本版按 GitHub Actions 运行 Python 回归测试、B1–B4 示例成图校核和 Windows x64 便携打包冒烟测试。未实现的焊接锚固件模块、多面异形、异形剪切深度自定义、长模块自动比例适配和三维绘图内核不属于本次发布范围。
